# 🦅 까치매스 (KKACHI MATH) - 고1 수학 공식 12장 짝맞추기 웹앱

고등학교 1학년 수학의 핵심 개념과 공식을 **12장(6쌍) 카드 뒤집기 게임**으로 쉽고 재미있게 익히는 수업용·자습용 웹앱(PWA)입니다.

## ✨ 주요 기능
- **즉시 시작하는 12장(4×3) 카드 보드**: 복잡한 회원가입이나 방 코드 없이 열자마자 바로 플레이 가능
- **고1 수학 5대 단원 탑재**:
  1. 다항식 · 인수분해
  2. 복소수 · 이차방정식
  3. 도형의 방정식 (직선 · 원 · 이동)
  4. 집합 · 명제 · 함수
  5. 경우의 수 · 순열 · 조합
- **👀 3초 전체 힌트**: 12장 카드 앞면을 3초 동안 동시에 공개하여 순간 기억력과 집중력 향상
- **🆚 2팀 대결 모드 (A팀 vs B팀)**: 분단/모둠 대항전 지원 (짝을 맞춘 팀은 연속 찬스 획득)
- **✏️ 내 문제 직접 넣기**: 오늘 수업할 공식 6쌍을 즉석에서 입력하여 커스텀 카드판 생성 (브라우저 자동 저장)
- **📲 PWA 모바일 앱 설치 & QR 공유**: Vercel 배포 주소의 QR코드를 자동 생성하며 스마트폰 홈 화면에 앱으로 설치 가능

---

## 🚀 GitHub & Vercel 배포 방법

1. **GitHub 저장소에 업로드**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 까치매스 고1 수학 공식 짝맞추기 웹앱"
   git branch -M main
   git remote add origin https://github.com/<내-아이디>/<저장소-이름>.git
   git push -u origin main
   ```

2. **Vercel 연결 (원클릭 배포)**
   - [Vercel 대시보드](https://vercel.com/new)에 접속하여 **Import Git Repository**에서 해당 GitHub 저장소를 선택합니다.
   - `vercel.json` 설정이 이미 포함되어 있으므로 별도 설정 변경 없이 바로 **[Deploy]** 버튼을 누르면 `https://...vercel.app` 주소가 생성됩니다.
   - 배포된 주소에서 우측 상단 **`[📲 스마트폰 QR · 앱 설치]`** 버튼을 누르면 해당 Vercel 주소의 QR코드가 자동으로 화면에 표시됩니다.
